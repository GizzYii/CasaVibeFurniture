# Furniture Collection

## Description

This project is a simple **Furniture Collection website** that showcases different types of furniture such as sofas, chairs, beds, and more. The layout is responsive and clean, created using **HTML**, **CSS**, and **Bootstrap**. This demo serves as an introductory project to practice the basics of **HTML**, **CSS**, and **Bootstrap** integration.

## Features

- **Responsive Layout**: The site layout is designed to be responsive, adjusting for different screen sizes.
- **CSS Styling**: Custom styling for each section, using modern CSS techniques.
- **Bootstrap Components**: Use of **Bootstrap's grid system** to structure the page and **Bootstrap's utility classes** for spacing and alignment.
- **Image Showcase**: Each furniture category is showcased with an image and a description.
  
## Technologies Used

- **HTML**: The structure of the page, including the content and layout.
- **CSS**: Custom styling for elements, focusing on responsive design and modern styling techniques.
- **Bootstrap**: Bootstrap 5 framework to make the page responsive and utilize pre-built styles and components.
